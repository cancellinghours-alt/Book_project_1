Number Systems and Boolean Algebra

Introduction to Number Systems

A number system is a systematic way of representing numbers. In computing, different number systems are used for various purposes, from internal processing to data representation.The value of a digit in a positional number system depends on the digit itself, its position within the number, and the base (or radix) of the number system.


Number System Conversions

Converting numbers between different bases is a critical skill in computer science. Here, we'll cover the most common conversions.



1. Decimal to Binary, Octal, and Hexadecimal Conversion

To convert a decimal number to another base, we use the division-remainder method. Divide the decimal number by the target base repeatedly, noting the remainders at each step. The remainders, read from bottom to top, form the number in the new base.


2. Binary, Octal, and Hexadecimal to Decimal Conversion

To convert a number from any base to decimal, multiply each digit by its corresponding positional weight(base raised to the power of its position) and sum the results. Positions are counted from right to left, starting with 0.
