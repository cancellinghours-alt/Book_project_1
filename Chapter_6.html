Web Technology - I


Concept of Web Technology

Web technology refers to the tools, languages, standards, and techniques used to create, develop, maintain, and access websites and web applications. It enables computers and other devices to communicate and share information over networks.


Internet and World Wide Web

Internet

The Internet is a worldwide network of interconnected computers and devices that communicate and exchange information using standard communication protocols.


World Wide Web

The World Wide Web is a collection of interconnected web pages and resources that are accessed through the Internet using web browsers.


HTML

HyperText Markup Language

HTML is the standard markup language used to create and structure web pages. It uses tags and elements to define headings, paragraphs, links, images, tables, forms, and other content.


CSS

Cascading Style Sheets

CSS is a style sheet language used to control the appearance and layout of web pages. It is used to define colors, fonts, spacing, borders, backgrounds, and positioning of HTML elements.


Web Browser

A web browser is application software used to access, retrieve, and display web pages and other resources available on the World Wide Web. Examples include Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, and Opera.


Web Server

A web server is a computer system or software that stores and delivers web pages and other resources to clients through a network.


URL

URL stands for Uniform Resource Locator. It is the address used to locate a particular resource on the Internet, such as a web page, image, or file.
