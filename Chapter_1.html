Computer Fundamentals

Introduction of Computer

A computer is an electronic device that accepts raw data and instructions from users, processes it according to a given set of instructions, stores the processed data, and produces meaningful information as output. The word "Computer" is derived from the Latin word "Computare," which means 'to calculate'. Modern computers are versatile machines capable of performing complex mathematical calculations accurately and quickly, as well as handling tasks like creating documents, videos, games, and presentations.


History of Computer

The history of computers dates back to the early 19th century when Charles Babbage, an English mathematician, designed the first mechanical computer called the Analytical Engine. This machine was capable of performing basic arithmetic operations and had a memory unit for storing data. However, it was never built during Babbage's lifetime due to technological limitations.


Generations of Computer

Computers have evolved through several generations, each marked by significant technological advancements and changes in their architecture. The five generations of computers are as follows:



First Generation (1940s-1950s)

The first generation of computers used vacuum tubes for circuitry and magnetic drums for memory
  • They were large, expensive, and consumed a lot of power.
  • Programming was done in machine language.
  • Examples: ENIAC, UNIVAC I.


Second Generation (1950s-1960s)

The second generation of computers used transistors for circuitry and magnetic core memory
  • They were smaller, faster, and more reliable than the first generation.
  • Programming was done in assembly language.
  • Examples: IBM 1401, CDC 1604.


Third Generation (1960s-1970s)

The third generation of computers used integrated circuits for circuitry and semiconductor memory
  • They were smaller, faster, and more reliable than the second generation.
  • Programming was done in high-level languages.
  • Examples: IBM System/360, DEC PDP-11.


Fourth Generation (1970s-1980s)

The fourth generation of computers used microprocessors for circuitry and dynamic random-access memory (DRAM)
  • They were smaller, faster, and more affordable than the third generation.
  • Programming was done in high-level languages.
  • Examples: IBM PC, Apple II.


Fifth Generation (1980s-present)

The fifth generation of computers uses artificial intelligence and parallel processing
  • They are designed for natural language processing and expert systems.
  • Programming involves AI languages and frameworks.
  • Examples: Supercomputers, AI systems.
